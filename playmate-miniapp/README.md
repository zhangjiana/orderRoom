# 一起玩 · 微信小程序

原生微信小程序本地体验版，面向家长的周末约玩产品。源文件可直接导入微信开发者工具，无需 npm 安装或前端构建。

## 打开体验

1. 微信开发者工具 → 导入项目。
2. 选择本目录 `playmate-miniapp`，编译类型选择「小程序」。
3. 使用工具提供的测试号，或在 `project.config.json` 填写你自己的 AppID。当前占位值是 `touristappid`。
4. 普通编译，首页点击「家庭资料」，填家长昵称与孩子年龄。
5. 选择示例约玩 → 确认陪同 → 报名 → 到「我的约玩」查看；可退出报名。
6. 「发起约玩」填写未来日期、公共地点和人数，发布后本人自动加入。
7. 已结束且参加过的活动可记录再约意愿；所有活动均可作为模板发起新约玩，日期自动重置到明天。

示例数据在首次启动生成，保存后不会每天重新生成。清除该小程序本地缓存会删除所有体验数据，下次启动重新生成。

## 已实现

- 四个导航页及详情、家庭资料，共六个原生页面。
- 类型和适龄筛选；活动创建、报名、退出、发起者取消。
- 成行、未成行、进行中、已结束状态计算；满员、重复、年龄和时间校验。
- 本地数据持久化、写入失败反馈、单方再约意愿与再次发起。

## 范围说明

这是本地交互体验版，不是已上线的多人服务。没有微信登录、地理位置/距离计算、共享数据库、真实家庭匹配、订阅提醒、消息发送、报名审核、举报处理或双向玩伴关系。演示活动均有显著标记；不传输儿童资料，不含任何真实家庭信息。不能通过转发让其他设备看到本地创建的数据，因此不提供误导性的活动分享按钮。

真实试点前，需接入家长身份、服务端权限与并发容量控制、共享数据、内容审核与举报、隐私授权和提醒；AppID/后端环境需另行配置，产品所需类目与审核要求需按提交时的平台规则核实。
